# LLM Inference Model Options Comparison

## Overview
This document compares two realistic model-running options for the team's available laptops/hardware[cite: 1].

## Option A: Local Micro-Model via Ollama (Recommended Starter)
* Models: Qwen2.5-1.5B or Phi-3-mini[cite: 1].
* RAM / VRAM Requirements: Low to Moderate (~4 GB to 6 GB RAM/VRAM).
* Installation Complexity: Very Easy[cite: 1].

## Option B: HuggingFace Transformers with 4-Bit Quantization
* RAM / VRAM Requirements: Moderate (~6 GB to 10 GB RAM/VRAM).
* Installation Complexity: Moderate[cite: 1].

## Recommendation
We recommend starting with Option A (Ollama with a micro-model) to quickly establish the pipeline[cite: 1].
